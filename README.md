# 🧮 Sum of Two Numbers – Python GUI Application

## 📌 Project Overview

**Sum of Two Numbers** is a simple desktop-based Graphical User Interface (GUI) application developed using Python and Qt Designer.

The application allows users to enter two numerical values and calculate their sum with a single click. It provides a simple, interactive, and user-friendly interface for performing basic addition operations.

## ✨ Features

- **User-Friendly Interface:** Simple and easy-to-use graphical interface.
- **Number Input:** Accepts two numerical inputs from the user.
- **Instant Calculation:** Calculates the sum with a single button click.
- **Result Display:** Displays the calculated result directly on the interface.
- **Reset Functionality:** Allows users to clear the inputs and start a new calculation.
- **Exit Option:** Allows users to close the application easily.

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/akhila126/add-two-numbers.git
```

### 2. Navigate to the Project Directory

```bash
cd add-two-numbers
```

### 3. Install Dependencies

Install the required PyQt package:

```bash
pip install PyQt5
```

### 4. Run the Application

Run the main Python file that connects your frontend and backend.

```bash
python proBE.py
```

*Note: Make sure the frontend, backend, and UI files are in the correct locations and that the Python entry point matches your project setup.*

## 💡 How It Works

1. Launch the application.
2. Enter the first number.
3. Enter the second number.
4. Click the **ADD** button.
5. View the calculated sum.
6. Use the **RESET** button to perform another calculation.
